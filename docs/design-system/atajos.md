# Atajos de teclado

Todos los que maneja la app. Al añadir uno: que no choque con estos, que no salte dentro de un campo de texto y que tenga su botón (el atajo nunca es la única forma).

## En toda la biblioteca

| Tecla | Qué hace |
| --- | --- |
| ⌘K / Ctrl+K | En un tablón con buscador abajo: lleva al buscador (despliega la barra si está plegada) y, pulsado otra vez, lo suelta; nunca abre la paleta ahí. En el resto de vistas, abre o cierra la paleta de comandos |
| ⌘K → "Abrir el brief" | Con un proyecto abierto, lleva a su Sistema y abre el panel Brief (desde el tablero también) |
| N | Añadir referencia (fuera de campos y sin diálogos abiertos) |
| / | Lleva al buscador (si la barra del tablón está plegada, la despliega antes) |
| / con el ratón sobre una tarjeta | Se la entrega al agente como "esto" |
| ⌘B / Ctrl+B | Pliega o despliega la barra lateral |
| ⌘B · ⌘I · ⌘K (escribiendo una referencia de texto) | Negrita, cursiva y enlace en Markdown sobre lo seleccionado; ahí no pliegan la barra ni abren el buscador o la paleta. Enter sigue una lista y Esc sale del texto |
| ⌘/Ctrl + rueda, o pellizco | Zoom de columnas del tablero; en Pulido, tamaño del tornado |
| ⌘/Ctrl/Shift/Alt + clic en una pestaña | Lo que haría el navegador con un enlace |
| ⌘/Ctrl o Shift + clic en una tarjeta | La selecciona; con Shift, el tramo desde la última elegida |
| ⌘A / Ctrl+A con algo seleccionado | Selecciona todo el tablero a la vista (botón "Seleccionar todo" de la barra) |
| Esc con algo seleccionado | Suelta la selección |

## Buscador

| Tecla | Qué hace |
| --- | --- |
| ↑ ↓ | Moverse por las sugerencias |
| Enter / Tab | Tomar la sugerencia; Enter sin recorrer la lista manda la orden al agente |
| ⌘Enter | Mandar al agente |
| Retroceso con el campo vacío | Quita el último chip y luego el objetivo |
| Esc | En cascada: cierra la lista, vacía, quita chips, quita objetivo, suelta el foco |

## Ficha de referencia y conversación

| Tecla | Qué hace |
| --- | --- |
| Esc | Cierra la ficha (no si hay lightbox o diálogo abierto) |
| ← → / Esc | Navegar y cerrar el lightbox |
| Enter / Shift+Enter | Enviar o guardar / salto de línea |
| ⌘V | Pegar una imagen en un comentario |
| Espacio / K con el foco en un vídeo | Reproducir o pausar (también clic en el vídeo cuando ya suena; mudo, el clic le da sonido) |
| M con el foco en un vídeo | Sonido sí o no (botón de sonido) |
| F con el foco en un vídeo | Pantalla completa (botón, o doble clic en el vídeo) |
| Doble clic en la papelera de una tarjeta | Borra la referencia (el primer clic pide el segundo) |
| Esc en una tarjeta | Cancela el borrado a medias (también se cancela al sacar el puntero o solo a los 6 s) |

## Pulido

| Tecla | Qué hace |
| --- | --- |
| ← | Olvidar la tarjeta de delante (vuelve al Inbox); en un espacio de equipo, votar que salga |
| → | Conservarla (se queda en el tablón); en equipo, votar que se quede |
| Rueda o arrastrar | Pasar de una tarjeta a otra sin decidir |
| Enter | Abrir la ficha de la tarjeta de delante (sola: ← → no pasan a otra) |
| ⌘Z / Ctrl+Z | Deshacer la última decisión |

## Sistema y criterio.md

| Tecla | Qué hace |
| --- | --- |
| C | Modo comentar con pines (fuera de campos) |
| Enter | Enviar el pin |
| ⌘Enter | Guardar al momento un bloque editable o una ficha de área |
| Esc | Salir del modo pines, cerrar el área abierta, soltar la referencia que se arrastra |
| Enter / Espacio | Abrir una ficha o referencia con el foco |

## Proyectos

| Tecla | Qué hace |
| --- | --- |
| Enter en Inicio | Crea el proyecto con ese nombre |
| ⌘/Ctrl+Enter en la Isla | Proyecto nuevo desde la frase |
| Enter / Esc al renombrar | Guarda / cancela |
| ⌘V en proyecto vacío o Inbox | Sube la imagen pegada |
| Esc en un ejemplo | La cierra |
