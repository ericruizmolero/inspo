title: Criterio se centra en landings y salen las skills de iconos, logo y figura isométrica
date: 2026-11-04
status: vigente
kind: producto
---
**Contexto.** Alberto decidió el 04-11 centrar el producto en landing pages, para freelancers y estudios que las hacen para clientes y equipos internos que hacen muchas para una marca.

**Decisión.** Salen `icons`, `logo-svg` e `iso-figure` de `MD_SKILLS`, de `lib/md-skills-more.ts`, de `lib/area-skills.ts`, de `skills/` y de `marketing-site/src/skills.ts`. Las áreas Iconografía y Logo siguen en el criterio.md sin skill propia. Quedan once skills generadas. `microcopy` y `no-ai-slop` se funden en la skill `copy` cuando llegue.

**Por qué.** Alberto: "trim". Interpretación nuestra: una skill que no ayuda a una landing resta foco en el catálogo.

**Cómo aplicarlo.** Una skill nueva entra solo si sirve a una landing. La lista de ejemplos se recorta con el mismo criterio.
