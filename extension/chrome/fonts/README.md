# Fonts

The two typefaces of the Criterio design system, bundled so the popup and the import page load nothing
from Google at runtime (the extension makes no third-party calls).

| File | Family | Axes | Source |
|---|---|---|---|
| `archivo-latin.woff2` | Archivo | wght 400 to 700 | fonts.gstatic.com/s/archivo/v25 |
| `bricolage-grotesque-latin.woff2` | Bricolage Grotesque | opsz 12 to 96, wght 700 to 800 | fonts.gstatic.com/s/bricolagegrotesque/v9 |

Downloaded on 2026-10-07 through the Google Fonts CSS API (`fonts.googleapis.com/css2`), latin subset
only (U+0000-00FF and the usual punctuation, enough for English and Spanish).
