Where it goes

From X

Opens your bookmarks on x.com in a new tab and scrolls through them; each post found is saved here. Keep that tab open until it finishes. You need to be signed in to X in this browser.

Chrome asks for permission to read x.com; it is only used while importing.

From Pinterest

Paste the address of one of your boards. Each of its pins is saved as an image, sections included. A secret board needs you signed in to Pinterest in this browser.

Chrome asks for permission to read pinterest.com; it is only used while importing.

From this browser

Pick the folders. Only web pages are imported; the folder names stay here.
